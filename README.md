# NutriPlan — Adaptive Meal Planning Based on Lifestyle

NutriPlan is a full-stack web application that generates personalized weekly meal plans and consolidated grocery lists based on users' dietary preferences, health goals, allergies, weekly budgets, and available cooking time.

## Project Scope

**Phase 1:** Deterministic rule-based meal recommendation system.

**Phase 2 (Future):** LLM-assisted personalization with independent hard-constraint validation.

## Technology Stack

- Frontend: React, TypeScript, Vite, Tailwind CSS
- Backend: Python, FastAPI
- Database: PostgreSQL
- ORM and migrations: SQLAlchemy, Alembic
- Development infrastructure: Docker Compose

## Core Features

- User authentication and profile management
- Nutrition profile calculation
- Seven-day meal recommendations
- Consolidated grocery lists
- Meal replacement
- User feedback and favourites
- Nutrition and spending dashboard
- Administrator panel
